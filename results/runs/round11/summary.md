## 为什么跟 R10 矛盾

### 理解差异的关键

| | R10 分位数分析 | R11 实际回测 |
|---|---|---|
| 评估方式 | 简单等权日收益累加 | qlib 完整回测引擎 |
| 包含因素 | 纯信号方向 | + 成本 + dropout + 涨跌停 + 持仓约束 |
| Q4 与 Q5 差距 | Q4: +13.87% / Q5: +13.29% （Q4 略好 0.58pp） | 噪声水平之下，被摩擦吞掉 |
| 选股逻辑 | "Q4 这层 100 只股票等权" | "topk=N 选信号 top N 只" |

### 关键混淆点

R10 说 "Q4 略好于 Q5" 意思是 **位置 301-400 名** 平均收益略好于 **位置 401-500 名**。
**但 topk=60 不是只选 Q4 那 100 只**，而是选 **位置 1-60**（信号最强的）——

```
topk=30:  选位置 1-30  ← 都是信号最强的核心 (Q5 的极小子集)
topk=60:  选位置 1-60  ← 添加位置 31-60 = 信号"次强"股 (Q5 中间)
topk=100: 选位置 1-100 ≈ Q5 (前 20%)
```

也就是说，加 topk **等于稀释强信号股**，而不是切换到 Q4。Q4 真正定义是 **位置 301-400** 的股票，在 topk 框架内永远不会被选到（除非 topk=400）。

### 真正能"覆盖 Q4+Q5" 的方法

要在 long-only 框架内同时持有 Q4+Q5 的股票，需要**反过来排序**：
- 选 60-80 percentile 的股票（Q4）+ 80-100 percentile（Q5）
- 不能用 topk 实现，要用分位数选股策略

但即使这样做，R10 的 Q4+Q5 平均 Sharpe ~0.66 仍低于 R8.5 实际 IR 0.45 折算后的水平，意义不大。

## R10 真正的启示（被本轮反证后更清晰）

R10 那个 **多空 spread Sharpe 0.82** 不是来自"位置 1-60 而非 1-30"，而是来自 **做空 Q1（位置 401-500 名）的反向信号**：

```
多空 spread Sharpe 0.82  
  ≈ Q5 long Sharpe 0.63  +  (-Q1) short Sharpe ~0.2 的贡献  +  market beta 对冲降波动
```

在 long-only 框架里**只买不卖**，根本拿不到底部 Q1 的反向信号。

所以：
- **B1+（调 topk）走不通** ← 本轮 confirmed
- **B1++（long-short 框架）才是 R10 真正指向的方向**

## 结论

- R8.5 (topk=30, n_drop=1) 在 long-only 框架内的最优地位**未被动摇**
- R10 的发现 actionable 含义需要 long-short 框架才能兑现
- **本轮"反证"本身的价值**：避免了"扩 topk 就能改善"这个错觉。
  也提醒：诊断分析（R10 纯信号能力）和实际回测（R11 含摩擦）的差距可能很大，
  纯信号分析的细微优势在 backtest 框架里会被各种摩擦吞掉。
